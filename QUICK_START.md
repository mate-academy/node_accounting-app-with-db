# 🚀 Швидкий старт - Бухгалтерський застосунок

## Що потрібно для запуску

### 1. PostgreSQL
- Встановіть PostgreSQL на ваш комп'ютер
- Створіть базу даних: `accounting_app`
- Або змініть налаштування в `config.js`

### 2. Node.js та npm
- Node.js версія 14 або вище
- npm або yarn

## 🏃‍♂️ Швидкий запуск

### Варіант 1: Автоматичний запуск
```bash
# Зробити скрипт виконуваним (тільки один раз)
chmod +x start.sh

# Запустити застосунок
./start.sh
```

### Варіант 2: Ручний запуск
```bash
# 1. Встановити залежності
npm install

# 2. Налаштувати базу даних (опціонально)
# Відредагувати config.js з вашими налаштуваннями

# 3. Ініціалізувати базу даних
node src/initDb.js

# 4. Запустити сервер
npm start
```

## 🔧 Налаштування

### База даних
Відредагуйте `config.js`:
```javascript
database: {
  host: 'localhost',
  port: 5432,
  username: 'your_username',
  password: 'your_password',
  database: 'accounting_app'
}
```

### Змінні середовища
Створіть файл `.env`:
```bash
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_USER=your_username
POSTGRES_PASSWORD=your_password
POSTGRES_DB=accounting_app
PORT=5700
NODE_ENV=development
```

## 🆘 Вирішення проблем

### Помилка з'єднання з PostgreSQL
1. Перевірте, чи запущений PostgreSQL
2. Перевірте налаштування в `config.js`
3. Переконайтеся, що база даних існує

### Помилки тестів
- Тести потребують запущеного PostgreSQL
- Перевірте налаштування з'єднання

### Помилки порту
- Змініть порт в `config.js` або `.env`
- Переконайтеся, що порт не зайнятий

## 📞 Підтримка

Якщо виникли проблеми:
1. Перевірте логи сервера
2. Перевірте налаштування бази даних
3. Переконайтеся, що всі залежності встановлені
